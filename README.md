# Stoo's Card Showcase

Crée une page d'accueil pour "Stoo's Cards", une vitrine de cartes TCG fan-made (créations Pokémon fan-made).

Style visuel :

Fond très sombre, presque noir (#0B0D12), ambiance "gaming/collector"

Accent principal : dégradé orange/ambre (#F5A623 → #FF6B35)

Typographie : une police sans-serif bold et italique pour les titres (type Space Grotesk), et une police monospace (type JetBrains Mono) pour les petits labels/badges

Pas de style SaaS générique (pas de cartes toutes identiques avec ombre grise, pas d'eyebrow en majuscules partout)

Structure de la page :

Navigation en haut : logo "Stoo's Cards" à gauche, liens "Accueil" / "La Collection" à droite, avec l'onglet actif mis en évidence par le dégradé orange

Section hero : un badge pill "Collection TCG fan-made", un grand titre "Stoo's Cards" (avec "Cards" en dégradé orange), une courte description ("Une collection de cartes fan-made, imaginée et dessinée carte par carte. Découvre, vote, collectionne."), un bouton CTA en dégradé orange "Voir la collection →"

Une ligne de statistiques sous le bouton : nombre de cartes, nombre d'extensions, nombre de types

À droite du hero : 3 cartes à jouer superposées en éventail (légèrement inclinées), avec emplacement pour image de carte et un petit badge (ex: "140 PV")

Le résultat doit être responsive et sobre, sans animations superflues.
